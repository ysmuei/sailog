## 주요 검증 사례

- 답장 시간 중앙값을 KPI·참여자 비교·통계 모델·JSON에서 제거했다. 평균 답장 시간과 구간별 분포는 유지한다. 상단 KPI는 3개로 재배치했다.
- 리포트 카드는 필요한 집계값만 받는 별도 모델을 Canvas에 그린다. 대화 원문·원본 파일명·내부 참여자 ID를 포함하지 않는다. PNG 바이너리 시그니처와 1080×1350 크기, 선택 기간의 실제 통계 반영, 기본 익명화, 명시적인 이름 표시, 모달 재진입 시 익명 재설정, 로즈/라벤더 선택, 다크 모드의 고정된 밝은 저장 색상, 실패 안내를 검증했다.
- 가상 데이터의 실제 PNG와 데스크톱/모바일 미리보기 스크린샷을 시각적으로 확인했다. 모달 접근성 검사에서 차트 컨테이너의 ARIA 역할 누락을 찾아 group 역할을 추가했고, 수정 후 axe 위반 0개를 확인했다. 카드 동작 중 외부 요청과 데이터 전송 요청이 없음을 검사했다.

- 확인된 PC 두 자리 연도 구분선 `YY년 M월 D일` 지원. 이 형식만 `20YY`로 해석하며 메타데이터에 `pc-short-year-txt`로 구분한다. 연도 경계·자정·여러 줄·잘못된 구분선 후 이전 날짜 재사용 방지를 가상 데이터로 검증했다.

  이 수정에서는 `vercel-react-best-practices`의 `js-hoist-regexp` 참고 문서를 확인하고, 날짜 구분선 정규식을 모듈 범위에서 재사용했다. 기존 Worker 처리 경로를 유지했다. 사용자가 지정한 파일의 로컬 호환성을 확인했지만 다른 카카오톡 버전의 두 자리 연도 변형 전체를 검증한 것은 아니다.

- PC/모바일 TXT, 한글·숫자 날짜, 오전/오후 12시, 24시간, 자정 넘김, 같은 시각의 원본 순서.
- UTF-8/BOM, CP949/EUC-KR, 여러 줄 본문, 잘못된 날짜·행, 미확인 형식 거부.
- CSV 쉼표·인용부호·줄바꿈과 실제 물리적 시작 행. 일반적인 사진 관련 문장을 미디어 자리표시자로 오인하지 않음.
- ZIP의 목차·개수·용량·압축률·위험 경로 거부. 미디어를 해제하지 않고 단일 TXT/CSV 추출.
- 연속 발화 마지막 메시지 기준 답장, 0초 답장, 세션 경계 포함 규칙, 세션 기준 변경.
- 빈 기간의 null 통계, 표본 경고, 정확한 최근/이전 30일 경계, 분모가 없는 증감률 미표시.
- 월/주 합계 일치, 참여자 선택, 텍스트 전용 길이·짧은/긴 답변 비율.
- 업로드·오류 안내·샘플 분석, 익명화가 설정/홈 왕복 후 유지됨, 기간 필터, 네 분석 화면, 다크 모드, 모달 Escape, 명시적 삭제.
- 실제 Worker의 CSV/ZIP 처리, 처리 중 Worker 취소 후 새 분석 성공.

프로덕션 테스트는 빌드 후 PowerShell에서 다음과 같이 실행했다.

```powershell
$env:SAILOG_E2E_PREVIEW = '1'
npm.cmd run test:e2e
```

실제 운영 파일에 맞춰 파서 문법을 추가할 때도 원문 대신 익명·가상 fixture를 사용해야 한다.

## 구현 결정

파싱·통계는 Worker 안에서 수행하고 UI에는 집계와 최소 메타데이터만 전달한다. Dashboard와 Recharts는 React.lazy로 분리한다. Tailwind 스캔 범위를 src로 제한해 설치 스킬의 예제 클래스가 빌드에 유입되지 않게 했다. Vite 개발 Worker 의존성을 사전 최적화해 첫 파일 분석 중 재최적화로 새로고침되는 문제를 막았다. 개발용 Vite 재연결의 로컬 blob Worker만 개발 서버 CSP에서 허용하며 프로덕션은 self-only를 유지한다.

최종 빌드의 초기 JS는 약 343 kB(압축 약 110 kB), 지연 로딩 대시보드 JS는 약 450 kB(압축 약 131 kB), 공통 CSS는 약 35 kB(압축 약 8 kB), 대시보드 CSS는 약 2.5 kB다. Worker는 약 152 kB이며 원문 처리 비용을 메인 스레드에서 분리한다. 이미지 변환 패키지를 추가하지 않았으며 실제 모바일 GPU 프레임 측정 결과로 해석하면 안 된다.

적용한 7개 스킬과 충돌 판단은 [디자인 시스템](design-system.md), 기능·실행·파서 문법·AI 확장은 [README](../README.md)에 기록했다. [AGENTS.md](../AGENTS.md)에 이후 개발의 우선순위와 개인정보·통계 기준을 남겼다.

## 남은 실제 환경 검증

PNG 저장은 Chromium에서 다운로드 파일까지 확인했다. 모바일 화면은 에뮬레이션이며 실제 iOS Safari·Android의 다운로드/사진 앱 저장 동작은 추가 검증이 필요하다.

모든 카카오톡 버전의 실제 내보내기 파일, 실제 iOS/Android 터치·스크린리더, 중급 모바일 기기 프레임 프로파일링은 검증하지 않았다. 자동 검사에서 위반이 없다는 것은 접근성 전체 인증을 의미하지 않는다. 실제 파일의 형식이 다르면 추정하지 않고 명시적인 파서와 테스트를 추가한다. AI는 인터페이스만 준비했으며 별도 동의·서버 API·근거 연결·보관 정책이 구현되기 전에는 연결하지 않는다.
